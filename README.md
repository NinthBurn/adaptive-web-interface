# Interface
A framework-free static website exploring the meanings and forms of "interface".

The website represents an interactive, one-page exploration of the word **interface**: its meaning, forms, types, and interpretations across different disciplines.

The project combines editorial-style typography, restrained visual design, and lightweight interactions to present a familiar concept from several perspectives.

### [TL;DR: Website here ↗](https://ninthburn.github.io/adaptive-web-interface/)

## Features
- Responsive layout for desktop, tablet, and mobile devices.
- Light and dark themes, with support for system color preferences.
- Persistent manual theme selection.
- Fixed top navigation and chapter navigation.
- Interactive carousels.
- Flip cards with definitions and examples.
- Accessible modal dialogs with keyboard support and focus management.
- Reduced-motion support.
- Image credits and source attribution.
- Basic SEO metadata.

## Built With

The project uses standard web technologies: **HTML5, CSS3 and vanilla JavaScript**

No frameworks, libraries, build tools, or package managers are required.

## Accessibility & Compatibility

The project aims to provide an accessible experience through:
- Semantic HTML and logical heading hierarchy.
- Keyboard-accessible interactive elements.
- Visible focus indicators.
- Accessible labels for controls and dialogs.
- Focus management and keyboard navigation in modal dialogs.
- Reduced-motion preferences.
- Responsive layouts and readable color contrast.
